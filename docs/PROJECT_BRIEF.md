# Project Brief

## Purpose
Create a memorable New Year 2027 website for two friends. It should feel thoughtful and personal, with a technically impressive shared opening but a restrained, intimate reading experience afterward.

## Audience and access
- There are two intended recipients.
- Both enter through the same opening experience.
- Each receives a separate invitation code that selects their own experience.
- Their journeys and endings remain separate. Do not invent a shared/converging ending.

## Experience structure
1. **Gateway (shared):** Start interaction, star explosion, particles converge to form “HAPPY NEW YEAR 2027”, CTA “View Your Journey From My POV”, invitation-code entry, then portal transition.
2. **Through My Eyes (personalized):** A simple page layout containing the creator's message. Content combines the recipient's personality and qualities with shared memories and the creator's perspective.
3. **Ending (personalized):** A separate, quieter conclusion with a personal message and New Year wishes.
4. **Your Turn (optional):** A lightweight, optional way for the recipient to respond. It must never feel like a request for validation or be required to complete the experience.

Pages 2 and 3 differ for each recipient. Page 4 is not yet confirmed.

## Current content status
No friend-specific content has been finalized. Do not fabricate names, interests, memories, inside jokes, messages, or personal traits. Use neutral placeholders until supplied.

## Non-goals for the initial build
- No social network, account system, analytics, or admin dashboard.
- No elaborate fantasy/mythological worlds for Page 2.
- No forced response on Page 4.
- No unnecessary backend or database before a real requirement exists.
